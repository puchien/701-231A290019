## Cấu trúc
- `index.html`: trang chủ
- `lythuyet.html`: phần lý thuyết
- `baitap01.html`, `baitap02.html`, `baitap03.html`: ba bài thực hành
- `baitap22.html`: ảnh kết quả Bài 22 được cung cấp
- `baitap23.html`: trang liên kết tới source Bài 23 được cung cấp
- `baitap23/`: source gốc của Bài 23
- `diemdanh.html`: thông tin nộp bài
- `images/avatar.jpg`: ảnh đại diện được cung cấp

## Xuất bản bằng iPad/iPhone
1. Giải nén ZIP trong ứng dụng Tệp (Files).
2. Tạo repository Public trên https://github.com/new.
3. Mở repository, chọn Add file > Upload files.
4. Tải lên các tệp và thư mục bên trong thư mục dự án sao cho `index.html` nằm ở thư mục gốc repository (không tải ZIP làm một tệp duy nhất).
5. Vào Settings > Pages.
6. Chọn Deploy from a branch, nhánh `main`, thư mục `/(root)`, rồi Save.
7. Chờ triển khai và mở Visit site để lấy URL.

Lưu ý: Bài 22 được đưa vào dưới dạng ảnh tổng kết kết quả mà sinh viên cung cấp, không phải source code gốc của bài 22. Hãy kiểm tra lại yêu cầu môn học để xác nhận định dạng này được chấp nhận.
